Audiobookshelf uses ID3 metadata tags in audio files to populate data.

Audiobookshelf writes these ID3 tags to the file exclusively during the initial download, meaning subsequent metadata edits within the app will not update the downloaded file. Embedded tags are parsed from the audio file into the server's database during the initial library scan or whenever a manual re-scan is explicitly triggered.
## ID3 Tag Mapping
| Audiobookshelf Field | ID3 Tag                                             | Read on Scan                                 | Written on Download         | Notes                                                                                                         |
|----------------------|-----------------------------------------------------|----------------------------------------------|-----------------------------|---------------------------------------------------------------------------------------------------------------|
| Podcast Title        | album / album-sort / movementname / series          | ✓ (`album` primary, `series` fallback)       | ✓ (`album`)                 | `movementname` and `album-sort` are written on download but ignored during scan.                              |
| Episode Title        | title / title-sort                                  | ✓                                            | ✓                           | `title-sort` is written on download but not read on scan                   |
| Podcast Author       | artist / artistsort / albumartist / albumartistsort | ✓ (`albumartist` primary, `artist` fallback) | ✓ (`artist`, `artist-sort`) | Used for Creator/Host(s). `artistsort` and `albumartistsort` are written on download but ignored during scan. |
| Season               | disc / discnumber                                   | ✓ (`disc` only)                              | ✓ (`disc`)                  | `discnumber` variant is ignored during scan.                                                                  |
| Episode Number       | track / series-part                                 | ✓ (`track` primary, `series-part` fallback)  | ✓ (both)                    | Specifies episode sequence.                                                                                   |
| Podcast Title        | MVNM                                                | —                                            | ✓                           | iTunes/M4B movement name field; written for broad player compatibility; not read back on scan.                |
| Episode Number       | MVIN                                                | —                                            | ✓                           | iTunes/M4B movement number field; written for broad player compatibility; not read back on scan.              |
| Episode Description  | comment                                             | ✓ (primary)                                  | ✓                           | The description tag is meant for long-form show notes and detailed episode summaries.                                                                          |
| Episode Subtitle     | subtitle                                            | ✓                                            | ✓                           | The subtitle tag holds a short, concise, one-sentence summary or hook designed for quick, at-a-glance display in podcast players.                                      |
| Episode Description  | description                                         | ✓ (fallback for `comment`)                   | —                           | Acts strictly as a fallback tag for the episode description field on scan; not written on download.           |
| Episode Type         | episode-type                                        | ✓                                            | ✓                           | Allowed values: `full`, `trailer`, `bonus`.                                                                   |
| Genres               | genre                                               | ✓                                            | ✓                           |                                         |
| Language             | language / lang                                     | ✓ (`language` only)                          | ✓ (`language`)              | `lang` variant is ignored during scan.                                                                        |
| Publication Date     | date                                                | ✓                                        | ✓                       | Full RFC2822 date string (`Day, DD Mon YYYY HH:MM:SS +0000`). Parsed to timestamp on scan. FFmpeg writes to the TDRC frame on download, causing tag editors like Mp3tag to display this as an extra YEAR or DATE entry. |
| Publication Date     | releasedate                                         | —                                        | ✓                       | Written as a copy of the RSS date string to the TDRL frame (displays explicitly as RELEASEDATE in Mp3tag); not read back on scan.                                                          |
| Publication Year     | year                                                | —                                        | ✓                       | Written as a 4-digit year string to the TYER frame (displays as YEAR in Mp3tag); not read back on scan.                                                                |
| Podcast Type         | podcast-type                                        | ✓                                            | ✓                           | Read at podcast level on scan. Values: `episodic` or `serial`.                                                |
| iTunes ID            | itunes-id                                           | ✓                                            | ✓                           | Read at podcast level on scan; written on download.                                                           |
