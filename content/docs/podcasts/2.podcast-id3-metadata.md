Audiobookshelf uses the ID3 metadata tags in audio files to populate data.
Ensure your settings for the metadata priority settings matches your file structure.

All tag names are **case-insensitive**.

## ID3 Tag Mapping

| ID3 Tag | Audiobookshelf Data | Notes |
|---------|---------------------|-------|
| album / movementname / series | Podcast Title | Multiple tag names supported for compatibility across tagging standards |
| title | Episode Title | Standard ID3 tag for episode name |
| artist / artistsort / albumartist / albumartistsort | Hosts | Multiple tag names supported for redundancy and compatibility; `artistsort` and `albumartistsort` are intended for sorting host names |
| composer / performer | Guests | Workaround tag since there is no standard ID3 field for guests; multiple names supported |
| discnumber | Season | Indicates season number if applicable |
| track / series-part / movement | Episode Number | Specifies episode sequence; supports decimal values for special episodes |
| comment / unsyncedlyrics | Episode Description | Multiple tag names supported for compatibility |
| genre | Genres | Multiple genres can be specified |
| language / lang | Language | Indicates episode language |
| publisher | Podcast Studio | Production company or organization |
| year / date / releasedate | Publication Date | Supports `YYYY-MM-DD` format in `year` tag for better compatibility |
| origyear | Publication Year | Original release year as a number |
| podcast | Podcast Flag | iTunes-specific tag identifying file as podcast content; typically set to `1` |
